# Week 1 — Values, Types and Input/Output

**Box we build this week:** `INPUT` and `OUTPUT`


## By the end of this week you can

1. Write and run a Python file that prints formatted output
2. Store values in well-named variables and say what type each one is
3. Explain why `"20"` and `20` are different, and convert between them
4. Calculate a difference and a percentage from values you were given
5. Ask the user for input and report results in a tidy, aligned report
6. Read an error message and say what kind of problem it is
